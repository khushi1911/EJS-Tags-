# EJS Tags

A simple web application that demonstrates **different EJS tags** by dynamically displaying content based on whether the current time has an **odd or even number of seconds**.

## Features

* Uses different EJS tags
* Displays dynamic content
* Checks the current time
* Shows different content for odd and even seconds
* Server-side rendering with EJS

## Tech Stack

* **Frontend:** HTML, CSS, EJS
* **Backend:** Node.js, Express.js
* **Language:** JavaScript

## How It Works

1. The application gets the current time.
2. It checks whether the current seconds are odd or even.
3. EJS conditional logic is used to determine what content should be displayed.
4. The corresponding content is rendered on the webpage.

## How to Run

1. Clone the repository.
2. Install the dependencies:

```bash
npm install
```

3. Start the server:

```bash
node index.js
```

4. Open the application in your browser.

## Purpose

This project was created to practice **EJS tags, conditional rendering, dynamic content, JavaScript logic, and Express.js**.
